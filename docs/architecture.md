# Архітектура AI-агента

## Призначення
Агент автоматизує створення, складання, тестування і перевірку TypeScript Hello World-проєкту для варіанта 6.

## Взаємодія компонентів

| Компонент | Призначення | Вхід | Результат | Перевірка |
|---|---|---|---|---|
| build-engineer.agent.md | Головні правила ролі | Вимоги лабораторної роботи | Безпечні зміни | Критерії завершення |
| project-scaffold | Створення проєкту | Мова і назва | package.json, src, tsconfig | Файли і scripts |
| build-and-test | Складання і тест | package.json, tsconfig | dist, test, ci scripts | `npm run ci` |
| github-actions | Налаштування CI | ci scripts | ci.yml | Три ОС у matrix |
| init | Оркестрація повного сценарію | Корінь репозиторію | Готовий проєкт | Послідовний `check` |

## Передача даних

1. git-init перевіряє репозиторій і .gitignore.
2. create-project створює TypeScript-вихід.
3. create-build отримує конфігурацію проєкту і створює тестові та ci-скрипти.
4. create-actions отримує робочі ci-скрипти і створює workflow.
5. check перевіряє файли, workflow, build і тестування.

## Обробка помилок

init зупиняється при першій помилці. Жодний наступний крок не запускається до усунення поточної. check не змінює проєкт і повертає нуль помилок лише за повного успіху. Заборонено приховувати помилки або оголошувати готовність без перевірки.
